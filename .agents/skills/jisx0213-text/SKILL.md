# jisx0213-text（文字の範囲と例外）

追跡しているテキストファイルの文字は JIS X 0213:2004 の範囲に収めます。CI の `agent-docs` ワークフローが `.github/scripts/check-jisx0213.py` で検査します。対象は文書だけでなく、Web 画面の文言（`web/`）、テスト、スクリプトのコメントも含みます。

## 判定の基準

- 基準は Project X0213 の公式対応表（`.github/scripts/data/jisx0213-2004-std.txt`）です。表は SHA-256 で固定しているため、編集しません。
- 範囲内とするのは、表の単独の符号位置、表にある 2 符号位置の結合列（`か゚` など）、表の注記にある Fullwidth/Windows の別表現、ASCII の印字文字、TAB、LF、CR です。
- Python の `euc_jis_2004` などの codec では判定しません。公式表と約 3,300 の符号位置で結果が異なります。
- 第3・第4水準漢字（表で `[2000]`/`[2004]` 印のある漢字）は警告です。`关`、`开` などの簡体字の一部もこの範囲に入るため、警告が出たら字体を確かめます。
- バイナリファイル（NUL を含むもの）とシンボリックリンクは検査しません。`vendor/` は submodule のため対象外です。

## 自分で書く文章

範囲外の文字は、次のように範囲内の文字や言葉に置き換えます。

| 範囲外 | 置き換え |
|---|---|
| `µ`（U+00B5 MICRO SIGN） | `μ`（U+03BC） |
| `≥` / `≤` | `≧` / `≦`、または「以上」「以下」 |
| 絵文字（`🥈`、`✅`、`⚠️` など） | 言葉にする（「2 位」「済」「注意」） |
| 簡体字（`这`、`说`、`载`、`动` など） | 日本の字体（這、説、載、動）。原文の引用ならそのまま残す（後述） |

`→`、`—`、`①`、`≒`、`±`、`×`、`°` は範囲内なので、そのまま使えます。画面の記号（チェック、警告など）も絵文字ではなく言葉か CSS で表します。迷ったら次のコマンドで確かめます。

```sh
python3 .github/scripts/check-jisx0213.py <file>
```

## 原文の引用

- upstream のエラー文、中国語の資料、英語ページの題名など、原文を正確に示す必要がある場合は、原文を書き換えません。
- Markdown では、コードスパン、コードブロック、引用行（`>`）のどれかで囲みます。地の文には書きません。
- `.github/jisx0213-allowlist.tsv` に `quote` 行を追加します。形式は `quote<TAB><パス><TAB><文字><TAB><理由>` です。`<文字>` には引用に含まれる範囲外の文字をすべて並べ、理由には出典を一言で書きます。
- `quote` は Markdown の引用の文脈だけで効きます。同じ文字が地の文にあればエラーです。Markdown 以外のファイルでは `quote` は効きません。
- 翻訳や要約は自分の文章として扱い、範囲内の文字で書きます。

## upstream 由来のファイル

- upstream から取り込んだファイル（ライセンス文、生成物など）を `vendor/` の外に置き、範囲外の文字が含まれる場合は `file<TAB><パスまたは glob><TAB>*<TAB><理由>` を追加します。理由には取り込み元を書きます。
- 自分で書くファイルを `file` で許可しません。

## 例外を足す前の確認

1. 自分の文章なら、置き換えます。例外にしません。
2. 原文の引用なら、引用の文脈で囲み、`quote` を足します。
3. upstream のファイルそのものなら、`file` を足します。
4. 文字や引用を消したときは、対応する allowlist の行も消します。使われていない行は CI でエラーになります。
5. 記録や引用の文言を、検査に通すために書き換えません。

## 確認

```sh
python3 .github/scripts/check-jisx0213.py           # 追跡しているテキスト全体
python3 .github/scripts/check-jisx0213.py --strict  # 警告もエラーとして扱う
sh tests/check-jisx0213/run.sh                      # 検査器自体のテスト
```
